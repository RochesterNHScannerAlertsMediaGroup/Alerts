# Repository instructions

## LiveLink core requirements

Before work, read the current [LiveLink Core Requirements](https://github.com/RochesterNHScannerAlertsMediaGroup/SAMG_Live_Link_Control/blob/main/CORE_REQUIREMENTS.md) on the control repository's main branch. It is the single living source of cross-system requirements. Refer to CORE IDs in implementation/review and record the reviewed version plus Git commit in handoffs. Preserve this repository's component safeguards; resolve conflicts explicitly and follow the latest authorized owner scope. Do not maintain a separate copy or treat requirements as deployment permission.
